# MeioNextStop

## 2.0.1

- Renamed from NextStop. Your settings carry over while the old folder is still installed;
  if your addon manager removed it, copy `WTF\Account\<account>\SavedVariables\NextStop.lua`
  to `MeioNextStop.lua` before logging in. `/nextstop` still works; then remove or disable the
  old NextStop addon (it says so in chat if it is still on)

## 2.0.0

- New name: LeaveButton is now Next Stop (folder `NextStop`, `/nextstop`; `/leavebutton`
  still works). Updating through an addon manager replaces the old folder; if you installed by
  hand, delete `LeaveButton` from your AddOns folder. A position you saved with Shift-drag
  resets once

## 1.1.0

- Sits beside FlareUI's Flight Timer bar while flying, when that bar is on
  (`/leavebutton beside on|off`)
- Settings panel: Esc > Options > AddOns > LeaveButton, also from the addon compartment
- Shows in the AddOns list under Meio, with a gryphon icon

## 1.0.0

- First release: a "get off at next stop" button on flight paths
